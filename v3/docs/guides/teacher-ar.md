# دليل الأستاذ المختصر

1. سجل الدخول بحسابك ثم افتح **أقسامي** أو **الطلاب**.
2. راجع القسم والوقت الظاهرين. بلّغ الإدارة إذا كان هناك اختلاف.
3. افتح بطاقة الطالب لتسجيل المتابعة أو التقييم.
4. لإسناد واجب، اختر الطالب أو القسم ثم راجع المستلمين قبل الحفظ.
5. لا تدخل بيانات مالية أو إدارية غير مطلوبة في ملاحظات الطالب.
6. تحقق من رسالة التأكيد بعد الحفظ، ثم راجع السجل عند الحاجة.
7. استخدم **الرسائل** للتواصل مع الإدارة، وسجل الخروج عند انتهاء العمل.
