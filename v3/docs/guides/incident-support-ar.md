# التعامل مع حادث تقني

1. دوّن الوقت والرابط والخطأ الظاهر، من دون نسخ كلمة مرور أو وثيقة.
2. تحقق من صفحة المنصة ثم من أحدث تنفيذ في GitHub Actions.
3. إن تعذر الدخول، لا تنشئ حسابات بديلة ولا تعدّل البيانات مباشرة.
4. إذا كانت البيانات معرضة للخطر، أوقف العمليات الحساسة وأبلغ المسؤول التقني.
5. استخدم سجل الحوادث: التاريخ، الخدمة، الخطورة، السبب، الإجراء، وقت العودة.
6. لا تبدأ استعادة قاعدة الإنتاج إلا وفق إجراء الاستعادة المعتمد وبموافقة المسؤولين.
