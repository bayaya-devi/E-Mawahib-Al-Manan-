# دليل الإدارة المختصر

1. افتح لوحة الإدارة بعد تسجيل الدخول وتحقق من المؤشرات الأساسية.
2. من **حالة المنصة** راجع قاعدة البيانات والملفات والتنبيهات التقنية. حالة النسخة الاحتياطية لا تعد ناجحة إلا بعد ظهور تنفيذ مؤكد في GitHub Actions.
3. عند إدارة حساب، استخدم الأرشفة بدلا من الحذف متى كان ذلك ممكنا.
4. لا ترسل وثائق الهوية عبر الرسائل ولا تنشر روابطها.
5. قبل أي ترحيل أو تعديل كبير، نفذ نسخة احتياطية وتحقق من نتيجتها.
6. عند حادث، فعّل الصيانة، احتفظ بسجل الوقت والخطأ، ثم اتبع `docs/DISASTER-RECOVERY.md`.
7. لا تنفذ استعادة على DARALQURAN مباشرة.
